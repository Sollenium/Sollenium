# Sollenium

> **An OS that rises every day, just like the sun.**

Sollenium is a custom operating system built from the ground up, with the goal of understanding and implementing the fundamental layers that make a computer operate.

## Status

**Early Development**

Sollenium is currently in the learning and groundwork stage. The operating system itself has not been implemented yet.

## vision

Sollenium aims to be a complete operating system developed from scratch, starting from the kernel and gradually expanding into a usable system.

The project is also a learning journey through:

* Computer architecture
* C
* Assembly
* Operating system design
* Low-level programming
* Memory management
* Processes and scheduling
* Filesystems
* Userspace

## Development

Sollenium is developed openly through this repository.

She project will prioritize understanding the underlying concepts rather than simply copying existing implementations.
