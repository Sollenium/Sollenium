## Status

**Early Development**

Sollenium is currently in the learning and groundwork stage. The operating system itself has not been implemented yet.

## Philosophy

Sollenium is built to understand, not simply to function.

Sollenium is an open-source operating system built from the ground up with a focus on transparency, freedom, learning, and experimentation. Its source code is intended to remain open, allowing anyone to study, modify, improve, and contribute to the project.

The project prioritizes understanding over abstraction. Hardware, architecture, memory, instructions, the kernel, and userspace should not be treated as black boxes. Each layer should be studied, understood, and implemented with purpose.

Sollenium does not aim to become a copy of an existing operating system. It aims to explore how an operating system can be designed and built from fundamental concepts while making the development process visible and understandable.

Existing operating systems, standards, documentation, and implementations may be used as references, but code should be understood rather than blindly copied.

Sollenium will grow incrementally. Every component should be built on a clear understanding of the layers beneath it, from the first instruction executed by the processor to the applications running in userspace.

The goal is not simply to create another operating system.

The goal is to understand how one works, and to build one openly from the ground up.

## Vision

Sollenium aims to be a complete operating system developed from scratch, starting from the kernel and gradually expanding into a usable system.

The project is also a learning journey through:

* Computer architecture
* C
* Assembly
* Operating system design
* Low-level programming
* Memory management
* Processes and scheduling
* Filesystems
* Userspace

## Development

Sollenium is developed openly through this repository.

The project will prioritize understanding the underlying concepts rather than simply copying existing implementations.
